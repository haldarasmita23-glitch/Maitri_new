# Maitri — Database Design

> **Document Status**: Approved design. Updated as the schema evolves.

---

## Database

- **Name**: `maitri_db`
- **Type**: MongoDB (NoSQL Document Database)
- **Local**: `mongodb://localhost:27017/maitri_db`
- **GUI**: MongoDB Compass

---

## Collections

### 1. `users`
Stores registered user accounts.

| Field | Type | Notes |
|-------|------|-------|
| `_id` | ObjectId | Auto-generated by MongoDB |
| `fullName` | String | Required |
| `email` | String | Unique, indexed |
| `phone` | String | |
| `password` | String | BCrypt hashed — NEVER plain text |
| `profilePhoto` | String | URL |
| `preferredLanguage` | String | Default: "en" |
| `location` | Object | `{ area, city }` |
| `role` | String | Always "USER" |
| `status` | String | ACTIVE \| SUSPENDED |
| `createdAt` | Date | Auto-set |

**Indexes**: `email` (unique)

---

### 2. `vendors`
Stores vendor/business accounts.

| Field | Type | Notes |
|-------|------|-------|
| `_id` | ObjectId | Auto-generated |
| `ownerName` | String | Required |
| `shopName` | String | Required |
| `email` | String | Unique, indexed |
| `phone` | String | |
| `password` | String | BCrypt hashed |
| `categoryId` | ObjectId | References `categories._id` |
| `description` | String | |
| `address` | String | |
| `latitude` | Double | |
| `longitude` | Double | |
| `openingTime` | String | Format: HH:mm |
| `closingTime` | String | Format: HH:mm |
| `images` | String[] | Array of URLs |
| `averageRating` | Double | Recalculated on each review |
| `verified` | Boolean | true when status = APPROVED |
| `status` | String | PENDING \| APPROVED \| REJECTED \| SUSPENDED |
| `createdAt` | Date | Auto-set |

**Indexes**: `email` (unique), `categoryId`, `status`

---

### 3. `categories`
Service categories (managed by Admin).

| Field | Type | Notes |
|-------|------|-------|
| `_id` | ObjectId | Auto-generated |
| `categoryName` | String | Unique |
| `categoryImage` | String | URL |
| `active` | Boolean | false = hidden from users |
| `createdAt` | Date | Auto-set |

**Initial categories**: Street Food, Tailors, Printing & Xerox, Mobile/Laptop Repair

---

### 4. `reviews`
User reviews and ratings for vendors.

| Field | Type | Notes |
|-------|------|-------|
| `_id` | ObjectId | Auto-generated |
| `userId` | ObjectId | References `users._id` |
| `vendorId` | ObjectId | References `vendors._id` |
| `rating` | Integer | 1–5 (validated) |
| `review` | String | Text of the review |
| `createdAt` | Date | Auto-set |

**Indexes**: `{ userId, vendorId }` (unique compound — one review per user per vendor)

---

### 5. `complaints`

| Field | Type | Notes |
|-------|------|-------|
| `_id` | ObjectId | Auto-generated |
| `userId` | ObjectId | References `users._id` |
| `vendorId` | ObjectId | References `vendors._id` |
| `complaintType` | String | Category of complaint |
| `description` | String | |
| `status` | String | PENDING \| IN_PROGRESS \| RESOLVED |
| `adminNote` | String | Optional admin comment |
| `createdAt` | Date | Auto-set |
| `updatedAt` | Date | Updated when status changes |

---

### 6. `chats`

| Field | Type | Notes |
|-------|------|-------|
| `_id` | ObjectId | Auto-generated |
| `senderId` | ObjectId | References users or vendors |
| `senderRole` | String | USER \| VENDOR |
| `receiverId` | ObjectId | References users or vendors |
| `receiverRole` | String | USER \| VENDOR |
| `message` | String | |
| `messageType` | String | TEXT \| IMAGE |
| `timestamp` | Date | Auto-set |
| `read` | Boolean | Whether receiver has read it |

**Indexes**: `{ senderId, receiverId }`

---

### 7. `notifications`

| Field | Type | Notes |
|-------|------|-------|
| `_id` | ObjectId | Auto-generated |
| `userId` | ObjectId | Target user/vendor/admin |
| `userRole` | String | USER \| VENDOR \| ADMIN |
| `title` | String | Short notification title |
| `message` | String | Notification body |
| `type` | String | GENERAL \| COMPLAINT \| REVIEW \| VERIFICATION |
| `read` | Boolean | false = unread |
| `createdAt` | Date | Auto-set |

**Indexes**: `userId`

---

### 8. `favourites`

| Field | Type | Notes |
|-------|------|-------|
| `_id` | ObjectId | Auto-generated |
| `userId` | ObjectId | References `users._id` |
| `vendorId` | ObjectId | References `vendors._id` |
| `createdAt` | Date | Auto-set |

**Indexes**: `{ userId, vendorId }` (unique compound — no duplicate favourites)

---

### 9. `admins`

| Field | Type | Notes |
|-------|------|-------|
| `_id` | ObjectId | Auto-generated |
| `name` | String | |
| `email` | String | Unique |
| `password` | String | BCrypt hashed |
| `role` | String | ADMIN \| SUPER_ADMIN |

---

## Security Notes

- Passwords are ALWAYS BCrypt hashed before storage
- ObjectId references are used instead of embedding full documents (to avoid data duplication)
- Unique compound indexes on `reviews` and `favourites` prevent duplicate entries at the database level
