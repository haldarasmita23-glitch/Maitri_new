> **Document Status**: Shell. Populated as features are implemented.

---

## Primary User Journeys (Planned)

### New User Journey
```
Landing Page
    ↓
Register (User Registration Form)
    ↓
Login
    ↓
Browse Categories
    ↓
Search / Discover Vendors
    ↓
View Vendor Detail
    ↓
[Optional] Add to Favourites
    ↓
Submit Review
    ↓
[Optional] Raise Complaint
```

### New Vendor Journey
```
Landing Page
    ↓
Vendor Registration Form
    ↓ (Pending verification)
Admin Reviews Vendor
    ↓
Admin Approves Vendor
    ↓ (Vendor receives notification)
Vendor Logs In
    ↓
Vendor Completes Profile
    ↓
Vendor Visible to Users
```

### Admin Verification Journey
```
Admin Login
    ↓
Admin Dashboard
    ↓
Vendor Management → Pending Vendors
    ↓
Review Vendor Details
    ↓
Approve OR Reject
    ↓ (Notification sent to vendor)
Vendor status updated
```
